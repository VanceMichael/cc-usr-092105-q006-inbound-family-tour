# 阿拉伯家庭入境行程履约

面向多人家庭团组入境旅行的团组履约领域资料，覆盖从展会询盘到跨城行程确认、成员分批变动与退款的完整履约关系。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 迪拜阿拉伯旅游展上，到访过北京和上海的游客提出八人家庭单独赴重庆的定制咨询
- 中外合作方跨时区对接，地接与供应商确认存在时延，须以版本化确认为准
- 家庭成员可分开到达或退出，费用分摊与已确认资源必须始终保持一致
- 阿拉伯语翻译作为独立服务报价与确认，任何一处供应商变动都可能使行程失效
- 企业差旅后追加休闲行程时，原商务资料不得默认用于休闲履约或营销

领域同时约定了报价过期、候补替换、临时改线、退款核算、最小化披露与全程调整可追溯等规则，保证领队始终只拿到一份全部相关方已确认的行程。

## 校验方式

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整。
