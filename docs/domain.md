# 领域约定

本领域描述入境游运营商面向多人家庭团组（以迪拜展会上八口之家单独赴重庆为典型场景）的团组履约服务：从询盘开始保存同行关系、证件资料授权、城市偏好、报价版本、翻译服务、地接确认与入境便利信息，直至成员变动、临时改线、退款等履约事件全部可追溯。

## 核心对象

- **询盘**：一次定制咨询的入口，记录来源渠道、客源地、目的地与语言需求；后续所有对象都挂在询盘之下。
- **团组成员**：团组中的个人。成员可以分开到达、中途加入或提前退出，成员状态变化不删除历史，只产生新的关联状态。
- **同行关系**：成员之间的家庭/从属关系与费用责任关系（如谁为未成年子女或随行长辈承担费用），用于成员拆分时维持费用责任完整。
- **证件资料与授权**：护照等证件资料及其授权记录。授权带有目的限制与范围，可撤回；商务段授权不自动覆盖休闲段或营销用途。
- **城市偏好**：目的地城市、已到访城市、饮食/住宿/行程节奏等偏好；偏好变更触发报价或行程升版。
- **报价方案（含版本与有效期）**：交通、住宿、翻译等分项报价的版本集合。每个版本带有效期，过期价格不得用于确认与履约。
- **交通与住宿资源**：跨城及城内交通、酒店等具体资源，资源与成员范围（全体/部分成员）和确认状态绑定。
- **翻译服务**：阿拉伯语等语种的口译/随行翻译安排，作为独立资源单独报价与确认。
- **供应商与地接确认**：境外组团方、境内地接社、各供应商跨时区的确认记录；行程版本只有在全部相关方确认后才对领队生效。
- **入境便利信息**：签证、免签/过境政策、入境申报等便利化信息，按成员国籍与到达批次分别适用。
- **行程版本**：不可变的行程快照。临时改线、候补替换、成员分批到达等都产生新版本，旧版本保留用于追溯。
- **费用分摊**：每个成员（或费用责任人）在当前已确认资源下的应付/已付/退款金额。资源或成员变化后必须重算并经确认。
- **候补与替换记录**：资源不可用时的候补位次、替换方案及其确认过程，原资源与替换资源都保留在案。
- **退款记录**：按已发生费用、取消费用与已确认资源约束核算的退款结果，回写费用分摊。
- **调整记录**：每一次变更的提议人、提议时间、受影响成员与资源、费用差额与确认链路，供运营人员解释“谁提出、影响谁、费用如何变化”。
- **对外披露视图**：面向单个供应商/合作方裁剪后的字段集合，遵循最小化披露，只含该方履约必需字段。

## 必须遵守的关系

- 成员加入或退出只重算与其关联的资源和分摊，不得被动改动其他成员已确认的资源。
- 费用分摊与已确认资源严格对应：任何资源确认、替换、取消或成员变化后，分摊必须重算并由相关方再次确认。
- 行程版本按版本链推进（询盘 → 报价 → 跨时区确认 → 变更升版 → 退款/分摊重算）；领队任何时刻只拿到一份全部相关方已确认的版本。
- 报价超出有效期即失效，须重新询价并升版；候补替换与临时改线同样生成新版本而非覆盖旧版本。
- 企业差旅结束后追加休闲行程时，须重新取得资料使用授权；原商务资料不得默认用于休闲履约或营销。
- 对外共享资料一律走披露视图：供应商只看得到其履约所需字段，证件资料共享须有授权依据，授权撤回后停止后续使用。
- 每条调整记录都能回答：谁提出、影响哪些成员与资源、费用差额多少、由谁确认。

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
