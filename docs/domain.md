# 领域约定

## 核心对象

- 询盘记录：从展会等渠道进入的定制咨询，是团组履约的起点
- 团组成员：随行人员，可分开到达或中途退出
- 同行关系：成员之间的家庭或同行关联，决定费用分摊与资源分组
- 资料授权：成员对证件等资料使用范围的授权记录
- 城市偏好：成员对目的地城市与体验的选择
- 行程版本：行程的每次有效形态，调整即产生新版本
- 报价方案：交通与住宿等资源的报价，含有效期与版本
- 翻译服务：阿拉伯语等语言服务的安排与确认
- 供应商确认：交通、住宿等供应商对资源的确认
- 地接确认：目的地地接社对接待安排的确认
- 入境便利信息：签证、口岸等入境便利政策信息
- 费用分摊记录：成员间的费用分摊明细，随成员与资源变动重算
- 候补资源：满额资源的候补中替换项
- 变更记录：每次调整的提出方、受影响成员与费用影响
- 退款记录：按变更核算到具体成员的退款
- 行程确认单：领队持有的、仅含各方已确认项目的行程

## 已知规则

- 家庭成员变更只影响关联资源
- 成员分开到达或退出时，费用分摊与已确认资源同步重算并保持一致
- 商务资料不得默认转作营销
- 企业差旅资料不得默认用于追加休闲行程的营销
- 对外共享仅包含履约必需字段
- 报价设有有效期，过期后须重新询价确认
- 候补资源替换须经相关成员授权后方可生效
- 临时改线须经领队与受影响成员确认后生成新的行程版本
- 退款按变更记录核算到具体成员
- 领队行程确认单仅包含各方已确认的项目
- 每次调整须记录提出方、受影响成员与费用影响
- 跨时区确认以统一截止时限为准

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
